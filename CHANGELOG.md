# Changelog

## 0.3.0

**Customer reviews for AI SDK tools.**

Use the ask tool for confirm, choice and text questions, and the AI SDK 7 approval gate for enforced permission. Recipient and action bindings survive exact retries; changed input requires a new review.

The saved-message recipe demonstrates delayed answers with application-owned SQLite coordination and execution receipts. The request-time helper still has a bounded wait.

Requires the shared Pushary SDK 2.1. Finish existing pending operations on their original SDK version before upgrading. The adapter is MIT-licensed; real phone delivery uses the hosted Partner service.

[Run or adapt the example](https://github.com/Pushary/pushary-ai-sdk/blob/main/examples/README.md).
